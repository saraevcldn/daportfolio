## Featured Projects

### 1. ReachEd — Education Resource Prioritization

**Best Capstone Award | FTW Foundation x Accenture Data Engineering Program**

ReachEd is a collaborative Data Engineering project designed to help Philippine local government units (LGUs) identify areas that may require greater attention in the allocation of public school classrooms and teachers.

The project integrates education, population, and geographic datasets to support consistent and data-informed resource prioritization.

**Technologies:** Databricks, SQL, Python, PySpark, Delta Lake, Git/GitHub

**My Contributions:**
- Profiled education, population, and geographic data sources to assess their structure and quality.
- Developed Bronze and Silver data pipelines for geographic boundaries and school-age population datasets.
- Built a geographic crosswalk to support matching records using Philippine Standard Geographic Codes (PSGC).
- Contributed to data modeling, including entity-relationship design and Gold-layer alignment.
- Supported data quality validation, documentation, and pull request reviews.
- Contributed to the team's approach for interpreting and prioritizing education resource needs.

**Repository:** [ReachEd — Education Access Intelligence](https://github.com/reached-hq/edu-access-intelligence)

### 2. NYC Mobility — Data Engineering Pipeline

A collaborative Data Engineering project that processes New York City mobility data alongside weather information to support reliable, repeatable analytics workflows.

The project applies data ingestion, transformation, validation, and orchestration concepts using Databricks.

**Technologies:** Databricks, SQL, Python, PySpark, Delta Lake, REST API, Git/GitHub

**My Contributions:**
- Worked on weather data ingestion using the Open-Meteo API.
- Implemented data quality checks with PASS, WARN, and FAIL outcomes.
- Contributed to Databricks Jobs dependencies and pipeline orchestration.
- Supported monitoring and validation of pipeline outputs.

**Repository:** [NYC Mobility Pipeline](https://github.com/saraevcldn/NEW-NYC-MOBILITY-PIPELINE)
